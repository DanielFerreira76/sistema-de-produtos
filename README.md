#  Consulta de Produtos

Projeto pessoal desenvolvido com **HTML5, CSS3, JavaScript e JSON**, que simula um sistema de consulta de produtos. A aplicação permite pesquisar produtos pelo nome ou código e visualizar suas informações em uma janela modal.

O objetivo é praticar manipulação do DOM, consumo de dados JSON, eventos JavaScript e desenvolvimento de interfaces responsivas.

> **Projeto em desenvolvimento**

## Acesse o projeto

[**Clique aqui para acessar a aplicação**](https://danielferreira76.github.io/sistema-de-produtos/)

O sistema possui produtos cadastrados com códigos de **1001 até 1020**.

## Funcionalidades

- Pesquisa de produtos por nome.
- Pesquisa de produtos por código.
- Busca dinâmica utilizando dados armazenados em JSON.
- Exibição das informações em uma janela modal.
- Apresentação de imagem, nome, código, preço e categoria do produto.
- Formatação automática de preços em Real (R$).
- Fechamento do modal pelo botão de fechar, clique fora da janela ou tecla `Esc`.
- Mensagens de retorno para pesquisas inválidas ou produtos não encontrados.
- Interface responsiva desenvolvida com a abordagem Mobile First.

## Tecnologias utilizadas

- **HTML5:** estruturação e organização dos elementos da página.
- **CSS3:** estilização, layouts responsivos e criação da janela modal.
- **JavaScript:** lógica de pesquisa, manipulação do DOM, eventos e exibição dinâmica das informações.
- **JSON:** armazenamento e organização dos dados dos produtos.

## Conceitos praticados

Durante o desenvolvimento deste projeto, são explorados conceitos importantes do desenvolvimento web:

- Manipulação do DOM com JavaScript.
- Seleção e alteração de elementos HTML.
- Eventos e funções.
- Consumo de arquivos JSON utilizando `fetch()`.
- Manipulação de arrays e objetos.
- Métodos de array, como `find()`.
- Manipulação de strings com `includes()` e `toLowerCase()`.
- Controle de classes CSS com `classList`.
- Criação e controle de janelas modais.
- Responsividade e abordagem Mobile First.
- Formatação de valores monetários com `toLocaleString()`.

## Objetivo de aprendizado

Este projeto faz parte da minha jornada de aprendizado em desenvolvimento web, com foco no aprimoramento das habilidades em JavaScript e na integração entre HTML, CSS e dados externos.

A proposta é evoluir gradualmente uma aplicação funcional, aplicando conceitos estudados e desenvolvendo uma melhor compreensão de como sistemas interativos funcionam na prática.
